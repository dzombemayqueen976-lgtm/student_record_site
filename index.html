Student Records

A simple student records manager built in C++ (Win32).

Download for Windows

Windows only · Windows 10 / 11

About

Student Records is a Windows desktop application that lets you add, search, and delete student records, each with an ID, name, age, and grade. It is built in C++ using the Win32 API and stores records in an array data structure.

Features

  • Add student records
  • Search by ID
  • Delete records
  • Duplicate-ID prevention
  • Live table view

How to run

  1. Download students_records_app.exe using the button above.
  2. Double-click the file to open it.
  3. If a blue “Windows protected your PC” screen appears, click More info, then Run anyway.

Why does this happen? Windows shows this warning for apps that aren't digitally signed. Code-signing certificates cost money, so it's normal for student projects like this one to be unsigned. The app is safe to run.
