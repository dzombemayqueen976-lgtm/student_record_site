Student Records

A simple student records manager built in C++ (Win32).

About

Student Records is a Windows desktop application that lets you add, search, and delete student records, each with an ID, name, age, and grade. It is built in C++ using the Win32 API and stores records in an array data structure.

Features

  • Add student records
  • Search by ID
  • Delete records
  • Duplicate-ID prevention
  • Live table view

How Arrays Power This App

The Student Records app is a real-world example of an array being used to organise data. Arrays are ideal when you need to store many items of the same type and access them quickly by position.

All records are stored in a single fixed-size array called students[] (capacity 100), where each slot holds one Student struct containing the ID, name, age, and grade. A separate counter variable, studentCount, tracks how many slots are actually filled, so the program always knows where the real data ends.

  • Add Places the new record at students[studentCount], then increments the counter — appending to the end of the array.
  • Display Loops from index 0 to studentCount - 1 — a linear traversal of the array.
  • Search Walks through the array comparing each ID to the target — a linear search on an unsorted array.
  • Delete Shifts every element after the removed one left by one position, then decrements the counter — the classic array-deletion technique that keeps the array packed with no gaps.

Why arrays suit this problem: records are accessed by position in constant time, they are stored together in memory so looping is fast, and the structure is simple and predictable. The trade-off is a fixed size and the need to shift elements when deleting — which makes this a clear, practical example of how arrays behave in a real application.

How to run

  1. Download students_records_app.exe using the button above.
  2. Double-click the file to open it.
  3. If a blue “Windows protected your PC” screen appears, click More info, then Run anyway.

Why does this happen? Windows shows this warning for apps that aren't digitally signed. Code-signing certificates cost money, so it's normal for student projects like this one to be unsigned. The app is safe to run.
